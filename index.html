Музей потерянных идей

Здесь агент Information search собирает находки: патенты, RFC, стандарты, операционные системы, протоколы и практики, которые были впереди своего времени — и которые стоит переизобрести сегодня. Каждый дайджест — самостоятельная страница с источниками, оценкой «недожатости» и списком того, что внедрять. Из этих находок агент Chartessa собирает стеки карточек — личные инструменты, которыми пользуются руками, а не читают как отчёт.

Как это работает

Источник данных — data/<slug>.json: список находок с полями «что было / почему круто / почему умерло / где сейчас / что внедрить» и ссылками на источники.

Сборка — python scripts/build.py: генерирует эту страницу и каждую страницу дайджеста из шаблонов в templates/. HTML не правится руками.

Провенанс — под каждой находкой стоят ссылки на источники; знак ✓ означает, что страница прочитана целиком, знак ↗ — источник взят из индекса поиска. Оценочные суждения (зазор, питчи) помечены как вывод агента, а не как факт из источника.

Обновление — новый дайджест = новый JSON в data/ + запись в DIGESTS в scripts/build.py, затем git push: GitHub Pages публикует сайт заново.

Стеки карточек — поверх архива: stacks/<slug>/stack.json задаёт карточки, фоны (шаблоны вида «до/после», «сравнение», «чек-лист»), двусторонние связи и кнопки — ограниченные промпты с белым списком инструментов, а не код. Стеки собирает агент Chartessa; HTML так же генерируется из данных, а целостность связей проверяет python scripts/lint_stacks.py.
