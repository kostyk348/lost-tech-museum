How it works

Data source — data/<slug>.json: findings with “what it was / why it mattered / why it died / where it lives now / what to build”, plus source links.

Build — python scripts/build.py generates this page and every digest page from templates/. The HTML is never edited by hand.

Provenance — every finding carries its sources; ✓ means the page was read in full, ↗ means the source came from a search index. Judgements (gap, pitches) are marked as the agent's conclusion, not as source facts.

Updates — a new digest = a new JSON in data/ + an entry in DIGESTS in scripts/build.py, then git push; GitHub Pages republishes the site.

Card stacks — built on top of the archive: stacks/<slug>/stack.json defines cards, backgrounds (before/after, comparison, checklist), two-way links and buttons — bounded prompts with a tool whitelist, not code. Stacks are assembled by the agent Chartessa; python scripts/lint_stacks.py checks their integrity.
